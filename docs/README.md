# docs/

Archived reports, audits, and specs — one file per topic. Kept for historical
context only. Most of these were written as work-in-progress notes and are not
meant to be read cover-to-cover.

For anyone actually trying to understand or run the project, start with:

- `../README.md` — what the project is, how to run it
- `DEPLOYMENT_CHECKLIST.md` — the only setup guide that's currently maintained
- `FEATURE_ROADMAP.md` — what's next
- `NSE_INVESTOR_AUDIT.md` — the original architecture pass

Everything else here is history. If you're contributing, don't add a new
`FIX_X_Y_REPORT.md` — write the "why" in the commit message and leave a
`# FIX X-Y —` block comment in the code at the fix site. That is what
future-you will actually read.
