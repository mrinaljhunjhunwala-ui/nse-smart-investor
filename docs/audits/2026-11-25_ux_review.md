# UX / data-display / typography review — 2026-11-25

Read-only review. Live app checked in Chrome at a 1396x632 viewport (laptop height) on 25 Nov 2026 ~01:10 IST (market closed, last session Mon 23 Nov). Pages visited live: Command Centre, Today, Analyze Stock (empty state), Tomorrow's Watchlist, Calibration, My Portfolio (PIN box shown, not unlocked), Paper Trades. Markets, Find Ideas, Watchlist & Notes, Quality Watch, Backtest, Angel One, Trading Tools and Investor Guide were reviewed from code only (time budget). The narrow-width check was not done live; mobile notes come from code.

## Keep as is
- Command Centre posture card ("Cautious. volatility above normal") — clear read with numbers.
- "last session (Mon 23 Nov)" labelling on deltas while the market is closed.
- ₹ with commas and 2 dp on prices; ▲/▼ plus colour for changes.
- Calibration "Is the model working? Too early to tell" card with progress bars.
- Previous-picks follow-through cards on the Watchlist.
- Short PIN-gate copy stating the 15-minute window.
- design.py type scale and palette tokens — the issue is pages bypassing them.
